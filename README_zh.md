# 视频笔记

一款 Chrome 侧边栏扩展，为任意网页视频创建带时间戳的标注片段。看教程、讲座、会议时，轻松记录结构化笔记。

## 功能

### 视频片段管理

- **添加片段**：通过下拉选择器、直接输入文本（`MM:SS` / `HH:MM:SS`）或交互式时间轴设置开始/结束时间。自动校验时间范围是否超出视频时长。
- **快速快照**：`Ctrl+Shift+S` 快照当前播放位置为开始/结束时间。
- **播放 / 暂停**：从片段开始时间播放。暂停后从当前位置恢复。
- **重置**：回到片段起始位置并重新播放。
- **循环播放**：每个片段独立开关——反复重放，直到手动停止。
- **删除**：移除单个片段。
- **时长显示**：每个片段显示持续时长（如 `1m 22s`）。

### 笔记（Markdown）

- 完整的 Markdown 编辑，编辑器下方实时预览。
- **格式工具栏**：粗体、斜体、代码块、插入图片。
- **截图捕获**：抓取当前视频帧嵌入笔记。同源视频使用 Canvas，跨域视频（YouTube 等）回退到 `captureVisibleTab`。
- **时间戳链接**：在笔记中写 `[01:23]` 或 `[1:02:30]`——渲染为可点击链接，点击跳转到视频对应时间点。
- **笔记模板**：预置摘要、行动项、会议记录模板。
- **插入图片**：通过 URL 插入图片（协议白名单：`http`, `https`, `data`）。

### 组织

- **标签**：每个片段用逗号分隔标签，以彩色徽章显示。按标签过滤。
- **搜索**：全文搜索笔记、时间范围和标签。
- **排序**：最新、最早、开始时间 ↑/↓、结束时间 ↑/↓、自定义拖拽排序。
- **标签着色**：片段根据第一个标签自动着色左边框，便于视觉区分。

### 批量操作

- 多选复选框、全选、清除选择。
- **删除选中**——支持撤销。
- **导出 JSON**——下载选中片段为 `.json` 文件。
- **导出 Markdown**——下载选中片段为格式化的 `.md` 文件，含时间戳、标签、笔记。
- **合并选中**——将多个片段合并为一个（最早开始、最晚结束、笔记合并、标签取并集）。
- **导入**——从先前导出的 JSON 文件加载片段（按 ID 去重）。

### 时间轴可视化

- 交互式时间轴，以彩色色块展示所有已有片段。
- 蓝色高亮显示当前选择范围。
- 点击设置开始时间，再次点击设置结束时间。结束时间小于开始时间时自动交换。
- 覆盖率统计条，显示已标记片段覆盖视频总时长的百分比。

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 播放 / 暂停当前片段 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `Ctrl+Shift+S` | 快照当前播放时间为开始/结束时间 |
| `Ctrl+Z` / `Cmd+Z` | 撤销（删除、合并、导入） |
| `Ctrl+Shift+Z` | 重做 |
| `?` | 显示所有快捷键 |

点击工具栏中的 `? Shortcuts` 按钮查看所有快捷键。

### 撤销 / 重做

- 50 步撤销栈，支持删除、合并、导入操作的撤销。
- 键盘快捷键。

### 历史记录

- 已访问视频页面列表，存储在浏览器本地。
- 一键重新打开或删除历史记录。

### 深色模式

- 通过标题栏的 ☀/🌙 按钮切换浅色/深色主题。
- 首次启动自动检测系统偏好。
- 偏好设置持久化到 localStorage。

### 国际化

- 中英文双语完整支持。
- 所有用户可见文本均在 `locales/` 中管理。

## 使用方法

1. 安装扩展。
2. 打开任意包含 `<video>` 元素的页面（YouTube、Bilibili、本地文件等）。
3. 点击扩展图标打开侧边栏。
4. 扩展自动检测视频，显示视频名称、时长和时间轴。
5. 点击时间轴设置开始/结束时间，点击 **添加时间段**。
6. 点击片段的编辑图标，添加 Markdown 笔记、标签、模板或截图。
7. 使用播放/暂停/重置按钮控制视频播放。
8. 导出笔记为 Markdown 或 JSON，方便分享或备份。

## 权限说明

| 权限 | 用途 |
|------|------|
| `sidePanel` | 侧边栏界面 |
| `scripting` | 向页面注入播放控制和视频检测脚本 |
| `activeTab` | 与当前标签页的视频交互 |
| `tabs` | 从历史记录打开和切换视频标签页 |
| `storage` | 持久化存储片段和历史记录 |
| `unlimitedStorage` | 存储截图图片 |
| `<all_urls>` | 检测任意网站的视频元素 |

## 技术栈

- [Plasmo](https://docs.plasmo.com/) — 浏览器扩展框架
- React 19 + TypeScript 7
- Tailwind CSS 3.4
- Marked（Markdown 渲染）+ DOMPurify（内容净化）

## 开发

```bash
pnpm install
pnpm dev      # 开发模式，热更新
pnpm build    # 生产构建
pnpm package  # 打包分发
```
